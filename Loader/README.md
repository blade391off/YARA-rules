# Malware Loader (Dropper)
Malware loader — це тип шкідливого програмного забезпечення, основне завдання якого полягає в тому, щоб непомітно проникнути в систему, обійти антивірусний захист та завантажити з віддаленого сервера іншу, більш небезпечну малвару
