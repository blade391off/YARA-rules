# 🦠 YARA RULES

This repository is created for **YARA rules** and for improving cybersecurity.

I plan to write and maintain many YARA rules here.
Thank you for reading and possibly supporting my work!

The first YARA rule in this repository is [`Generic_Malware.yar`](https://github.com/blade391off/YARA-rules/blob/main/Generic/Generic_Malware.yar).

---

##  About Me

My name is **Timofiy**.

I am interested in malware analysis, cybersecurity and YARA rule development.

I want to contribute to improving **cybersecurity in Ukraine** 🇺🇦.

I also have an account on [DOU](https://dou.ua/users/blade391off/).

---

## ⚠️ WARNING

This repository **will not contain malware samples or other executable files**.

The repository is intended for:

* 🦠 YARA rules
* 🔎 Malware detection research
* 🛡️ Cybersecurity
* 📚 Threat analysis
* 🧪 Defensive security research

In the future, I may add Python code that combines or processes the YARA rules.

```text

└── WinLock/                            # Screen lockers
```
