# Petya Ransomware

**Petya**  — це небезпечний комп'ютерний вірус-вимагач, який блокував доступ до системи, шифрував файли та пошкодив тисячі комп'ютерів по всьому світу у 2016–2017 роках, в основному торкнувшись України. 

Його найнебезпечніша версія **NotPetya** стирала дані назавжди, лише прикидаючись вимогою викупу для маскування своєї справжньої мети — масштабної деструктивної кібератаки.

Детальнішу інформацію про хронологію, механізм роботи та наслідки поширення цього шкідливого програмного забезпечення можна знайти на сторінці [Вікіпедії про Petya](https://wikipedia.org).
