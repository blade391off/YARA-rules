# Russia threat actors
Російські хакерські угруповання, які співпрацюють з владою РФ або безпосередньо контролюються нею, у міжнародній класифікації кібербезпеки зазвичай позначаються терміном APT (Advanced Persistent Threat) або асоціюються з назвами тварин (традиційно — «Bear» / «Ведмеді»). Зарубіжні спецслужби та провідні компанії у сфері інформаційної безпеки класифікують їх за приналежністю до конкретних відомств.
