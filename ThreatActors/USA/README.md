# USA threat actors
У сфері кібербезпеки урядові хакерські структури США класифікуються компаніями з інформаційної безпеки як APT (Advanced Persistent Threat). На відміну від класичних комерційних або злочинних хакерських угруповань, американські кібероперації проводяться штатними співробітниками спецслужб та військових відомств
