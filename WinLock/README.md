# Winlocker
WinLocker — це вірус-вимагач, який блокує операційну систему комп’ютера та вимагає грошей за розблокування

---
## Як він працює 
Блокує екран, робочий стіл або запуск програм 

Виводить загрозливе повідомлення з вимогою сплатити гроші через SMS, електронний гаманець або криптовалюту

Погрожує видаленням файлів або пошкодженням системи у разі відмови
